# Official brand assets

Hadukem supplies the official campaign-approved files in this directory.
Use SVG when available, with variants suitable for light and dark backgrounds:

- `mantle-light.svg` and `mantle-dark.svg`
- `fluxion-light.svg` and `fluxion-dark.svg`
- `xstocks-light.svg` and `xstocks-dark.svg`

Do not recreate or substitute unofficial logos. If official artwork is only
available as PNG, use the corresponding names with a `.png` extension and retain
the original proportions and brand requirements.

Stock logos use the `logo` URLs from the xStocks public assets API, stored with
the public token metadata in `packages/game-core/src/assets.ts`.
